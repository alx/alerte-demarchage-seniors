# Alerte — Démarchage prédateur ciblant les seniors

Document éducatif sur un schéma de vente abusif documenté par plus de 100 avis publics sur une période de 18 ans (2008–2026).

## Objectif

Informer les citoyens, les familles et les aidants sur les méthodes de démarchage à domicile prédateur ciblant les personnes âgées et vulnérables dans le secteur de la vente de tapisseries artisanales.

## Contenu

- Fiche du schéma (profil de l'opérateur, méthodes, durée)
- Statistiques clés (montants, valeurs réelles, durée des crédits)
- Les 7 étapes du schéma documentées
- Signaux d'alarme pour reconnaître ce type de démarchage
- Témoignages publics sélectionnés
- Arguments défensifs du vendeur vs. réalité documentée
- Actions à entreprendre en cas de victimisation
- Contacts des associations de consommateurs (DGCCRF, UFC-Que Choisir, CLCV, AFOC, CSF, FEVAD)

## Sources

Avis publics collectés sur Google Maps et GoWork.fr. Aucune information nominative sur l'entreprise mise en cause n'est publiée dans ce document.
